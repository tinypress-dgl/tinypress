一、技术栈总览

WPS 图片/视频模块是「本地批处理流水线 + AI 模型层 + 云服务」的三层结构：常规压缩、转换、尺寸、水印等重活走端侧自研引擎（快、离线、无上传）；AI 类能力（AI 压缩、抠图、OCR、字幕）由本地/云端部署的深度学习模型提供，敏感场景可切本地模式。

上图结构依据公开资料综合绘制（示意）：端侧引擎承担常规批处理，AI 能力本地/云端双模式，企业 AI 走云服务。分层边界为合理推断。

二、图片压缩引擎：分区 + 分层 + 重写

2.1 核心机制（三证据链）

机制依据证据
目标区域提取 + 分区压缩 + 融合金山办公公开专利「图像处理方法」（2024-10 公开报道，CNIPA 可查）：提取目标区域 → 整体压缩 → 融合目标区域得到第三图A 级
分层压缩（MRC 类）WPS 365「自研 MRC 分层与双层 PDF 技术」：前景文字/背景分层分别用最优算法；扫描件启用 JBIG2/G4；公章/手写签名优先保真；DPI 智能降级（压缩率 90%+）A 级
改进型 JPEG 编码器重写文件流第三方评测（太平洋科技 2026-02）：WPS 压缩图片采用改进型 JPEG 编码器重写文件流，非简单调参；配合 0–100 质量参数调节B 级

三者合起来即 WPS「AI 压缩」的完整链路：显著性分区（文字/人脸/产品细节=高价值区）→ 分区差异化量化 → 融合回填。官方称同体积下主观视觉质量提升约 30%（WPS 365 博客）。

三、AI 压缩：目标区域保真算法

  • 原理：从待压缩图提取「目标区域」（专利措辞），压缩整体后把目标区域按原质量融合回去——即「背景深压、重点保真」。
  • 高价值区类型（官方口径）：文字、人脸、产品细节；背景等非关键区域深度压缩。
  • 效果口径：文字/线条无损保留、OCR 识别率不下降；主观视觉质量 +30%（WPS 365，A 级）。
  • 落地形态：桌面端在「AI 压缩」档位触发；企业端（WebOffice）上传前自动压缩、单次 100+ 张、单张 50MB 流式防失败。
对 TinyPress 的启示：该算法可用开源显著性检测（如 OpenCV saliency、U2-Net）复刻「分区保真」思路，属合法可落地路线（P2）。

四、抠图技术：全局 + 局部多尺度分割

  • 专利证据：「抠图方法、装置」（CN202610692261.7，申请 2026-05-19，武汉/珠海/北京金山办公，已授权）：生成全局视图 + 多个局部视图 → 分别编码 → 全局特征与局部特征融合 → 分割。这是多尺度/局部注意力分割网络的典型架构（与 U²-Net 类思路同族）。
  • 产品口径：photo.wps.cn「AI 图像分割技术，识别人物/商品/动物/植物，最快 3 秒透明底」；PDF 侧「AI 图像识别引擎 + 智能抠图算法」提取签名/印章为透明 PNG。
  • 端云：在线抠图页（photo.wps.cn）为云端推理；客户端批量抠图为会员权益（推断走端侧或云侧，官方未明说）。
对 TinyPress 的启示：开源 U²-Net / rembg（ONNX）即可复刻同类分割能力（P2），无需自研模型。

六、视频转码技术：GPU 硬件加速引擎

  • 硬件加速编码：WPS 365 官方「内置行业领先的硬件加速编解码引擎，支持 NVIDIA、Intel 等 GPU 加速技术，4K/8K 批量转换速度提升 10 倍」——即 NVENC/QSV 类 GPU 编码路线（与 FFmpeg 硬件加速能力同源，官方未点名 FFmpeg）。
  • 格式覆盖：MP4/AVI/MKV/MOV/FLV/WMV 等 100+ 音视频格式双向互转。
  • 压缩策略：官方教程「视频大的原因是分辨率高、码率高，压缩就是降这些参数」——降分辨率 + 降码率 + 高压缩率编码；提供高/中/低三档。
  • 会员边界：1080P 以上清晰度、高级品质档位需会员；基础操作免费。
  • 企业 AI：智能剪辑、自动字幕、视频转音频（MP3/WAV）、长视频摘要/转写、AI 纪要——商业旗舰版 599 元/人/年，单视频上限 4 小时。
对 TinyPress 的启示：TinyPress v0.2.0 已实现同样的硬件加速闭环（NVENC/QSV/VideoToolbox 探测 + 软件回退），且「目标体积精确逼近」强于 WPS 等级制；100+ 容器转换仅需扩展 FFmpeg 封装参数（P0）。

七、架构推断与 TinyPress 对照（结论性）

7.1 WPS 技术画像（一句话）

自研端侧引擎（分层/分区/GPU 加速）+ TensorFlow 系 AI 模型 + 会员/云网关；AI 能力本地云端双模式，企业级 AI 走云。

7.2 TinyPress 技术画像（现状）

开源引擎全家桶（FFmpeg/mozjpeg/pngquant/libwebp/libavif）+ 本地批处理 + 硬件加速闭环；无 AI、无云、无会员墙。

7.4 对重新定位的三条技术结论

  • 压缩技术代差可复制：WPS 的「分区保真 AI 压缩」本质=显著性提取+分区量化，开源完全可落地——TinyPress 不输技术，只差功能面。
  • TinyPress 已有一项超越：目标体积精确逼近（CRF 二分 + 硬件码率迭代）强于 WPS 等级制；且全本地、无会员限次、无上传。
  • AI 能力全部有开源等价物：抠图（rembg）、OCR（PaddleOCR）、字幕（Whisper）均合法可落地；「AI 压缩」可用显著性检测先行实验。
