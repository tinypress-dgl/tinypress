TinyPress 重新定位与全功能路线图

对齐 WPS 图片批量处理 + 视频工具箱全部能力 · 全开源技术方案 · 专利规避红线
定位：本地批量媒体工具箱原则：零专利依赖、零代码抄袭、全开源范围：20 项能力全覆盖

一、重新定位声明

产品定义

TinyPress = 本地优先的批量媒体处理工具箱：图片与视频的批量压缩（精确目标体积）、格式转换、批量编辑（尺寸/旋转/裁剪/水印）、批量管理（重命名/替换源文件/转 PDF）一条流水线完成。无会员墙、无上传、无订阅、无限次。

目标用户与场景

  • 办公族：报名照 ≤200KB、邮件附件、微信/朋友圈体积限制、课件图批量压缩
  • 电商运营：商品图批量压缩 + 加水印 + 转格式 + 改尺寸（详情页/主图规格）
  • 创作者/MCN：视频批量压到平台上限（抖音/视频号）、批量转容器、字幕生成

不是做什么（边界）

  • 不做在线协作/云文档、不做订阅制、不做文档编辑
  • 不做屏幕录制、不做完整视频剪辑、不做云端 AI 纪要（P3 暂缓，定位不符）
  • 不实现任何 WPS 专利覆盖的方法（见第二章红线）

三大支柱（差异化）

  • 本地隐私：全本地处理、零上传——对 WPS（会员墙 + 云 AI）与在线工具的直接差异
  • 精确体积：目标大小二分逼近（视频 CRF 二分 + 硬件码率迭代），强于 WPS 等级制
  • 批量工程化：队列并发、取消/重试、崩溃恢复（jobs.json）、批量替换源文件

二、知识产权合规红线（先立规矩）

三条硬约束：① 不复制 WPS / 金山任何代码（独立开发，仅对齐功能语义）；② 不实现金山已公开专利权利要求覆盖的方法；③ 全部能力使用开源社区方案（附许可证），不引入闭源/侵权依赖。

六、里程碑验收标准

v0.3.0（P0 批量编辑）验收

  • 批量改尺寸：≤5 目标尺寸预设 + 自定义，lanczos 缩放，实测尺寸误差 ≤1px
  • 批量旋转/裁剪：90/180/270 + 任意角，裁剪区域可视化预览
  • 批量水印：文字/图片水印，透明度/位置/旋转参数化，批量输出一致性抽查
  • 视频容器转换：mkv/avi/webm/mov 互转 + mp3/wav 音轨提取，容器内编码不重编码（-c copy 优先）
  • 全部走队列，取消/重试/恢复可用；集成实测 ≥5 项通过

v0.4.0 / v0.5.0 验收

  • 转 PDF：无损嵌入（img2pdf），多图合并顺序稳定；替换源文件：默认备份 + 可回滚
  • 抠图：rembg 模型本地加载，人物/商品图边缘质量抽检；OCR：印刷体正确率 ≥95%（本地语料）
  • 字幕：faster-whisper 中文转写，SRT 时间轴对齐抽检
  • 编码器自适应压缩：libaom deltaq / x265 AQ 与普通档同体积下 PSNR/SSIM 不劣化即过
  • 合规自检：新增依赖逐项核对许可证清单，无 GPL 传染到主程序（外部二进制调用）
