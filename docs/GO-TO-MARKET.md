# TinyPress（速压）— 验证与发布方案

> 目标：在投入 W6-W8 打包发布前，用低成本内容验证需求真实性、收集意向用户。
> 原则：**产品的输出就是广告**（Screen Studio 打法）——压缩工具的演示视频本身就展示压缩效果，天然自证。

---

## 1. 验证目标与决策门槛

| 指标 | 门槛 | 达标后的动作 |
|---|---|---|
| 演示视频 B 站播放量 | ≥5,000 | 确认需求 → 进入 W6 打包 |
| 互动（点赞+评论+收藏） | ≥100 | 收集评论中高频需求词 → 调整 P0 预设 |
| 内测表单留资 | ≥30 人 | 发放内测 → 建立种子用户群 |
| 海外版（X/YouTube）播放 | ≥2,000 | 确认海外定价/文案方向 |

**未达标处置**：播放 <2k 且互动 <30 → 复盘定位（选题/演示形式/预设选择），换角度再投一轮，不进入开发重投入。

## 2. 演示视频方案

### 2.1 物料清单
| 物料 | 规格 | 用途 |
|---|---|---|
| B 站深度演示视频 | 3-5 分钟，横屏 16:9 | 主内容，讲透「免二压参数 + 多平台预设」 |
| 竖版短视频 | 60-90 秒，9:16 | 小红书 / 抖音 / 微信视频号传播 |

| 落地页 | 单页：痛点 → 演示 GIF → 定价 → 表单 | 承接流量（可用 HTML 快速搭建） |

### 2.2 B 站深度视频分镜脚本（3-5 分钟）

| # | 时间 | 画面 | 旁白/文案 | 目的 |
|---|---|---|---|---|
| 1 | 0:00-0:15 | 痛点开场：UP 主上传 B 站后画质被二压的对比图（上传前 vs 平台二压后） | 「你的视频传到 B 站，画质是不是总感觉被吃了？问题不在 B 站，在你的导出参数。」 | 共鸣钩子 |
| 2 | 0:15-0:40 | 展示传统流程：找教程、抄参数、命令行敲 FFmpeg | 「以前要么抄参数、要么装一堆软件，参数还经常失效。」 | 放大痛点 |
| 3 | 0:40-1:10 | TinyPress 演示：选择「B站 1080P（免二压）」→ 拖入视频 → 压缩完成 → 展示参数与 VMAF 分数 | 「选平台，拖进去，完事。内置小丸社区公认的免二压参数。」 | 产品亮相 |
| 4 | 1:10-1:50 | 批量演示：拖入 10 个文件 → 队列并行压缩 → 大小对比表 | 「批量并行，图片视频一起压。」 | 效率展示 |
| 5 | 1:50-2:30 | 图片感知压缩演示：拼多多主图 800KB → 96KB，放大对比画质 | 「电商主图压到 100KB 以内还不糊，靠的是感知压缩。」 | 差异化（Movavi 没做） |
| 6 | 2:30-3:00 | 多平台预设矩阵：B站/抖音/视频号/小红书/拼多多/朋友圈/证件照 | 「12 个平台预设，都是平台硬约束，不是瞎填的参数。」 | 矩阵价值 |
| 7 | 3:00-3:40 | 隐私卖点：断网演示、无账号 | 「全程本地，断网也能压，文件不出你电脑。」 | 信任建立 |
| 8 | 3:40-4:20 | 定价预告 + 内测招募 | 「买断制，一次买断含大版本升级。首批内测名额，评论区/置顶链接报名。」 | 转化钩子 |
| 9 | 4:20-4:40 | 结尾：参数来源说明 + 求三连 | 字幕标注「B站免二压参数来源：社区公开数据」 | 可信度 |

### 2.3 竖版短视频脚本（60-90 秒）
- 0-5s：钩子「为什么你的 B 站视频总被二压？」（对比画面）
- 5-30s：三连演示：选预设 → 拖入 → 完成（快节奏，每个动作 ≤5s）
- 30-50s：拼多多主图 100KB 演示（放大对比画质）
- 50-70s：买断价 + 内测报名 CTA（评论区）
- 结尾：品牌落版 + 关注引导

## 3. 投放计划

### 3.1 渠道与节奏（首轮 7 天）
| 天 | 动作 | 渠道 |
|---|---|---|
| D0 | 发布 B 站深度视频 + 置顶内测链接 | B 站 |
| D1 | 发布竖版短视频；X 发海外版 + 产品截图 | 小红书、X |
| D2 | V2EX / 少数派发帖（软性：「我做了个压缩工具，参数开源可查」）+ 知乎回答相关提问 | V2EX、少数派 |
| D3 | 技术圈口碑：GitHub 仓库公开（预设 JSON 开源）、Hacker News Show HN | GitHub、HN |
| D4-D7 | 跟进评论互动、收集留资、回复高频问题；数据复盘 | 全渠道 |

### 3.2 内容定位（避坑）
- 不做「免费神器」人设（吸引白嫖党），做「参数专业、结果可验证」人设（吸引付费用户）
- 视频里明确展示预设参数来源与 VMAF 数据，专业感本身就是转化力
- 不承诺「无损」（无损压缩是另一个赛道，避免口碑翻车）

### 3.3 内测转化漏斗
1. 视频/帖子 CTA → 落地页（演示 GIF + 定价 + 表单）
2. 表单收集：昵称 / 使用平台 / 最痛的文件类型 / 邮箱或微信
3. 发放方式：先到先得 30-50 份内测码（免费），要求反馈使用体验
4. 内测反馈 → 修复关键问题 → 公测定价发布
