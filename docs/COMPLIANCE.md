# TinyPress 合规与第三方组件清单

> 原则：**代码全部原创**；开源组件可用，但必须遵守其许可证；不复制任何产品的代码、UI 视觉资产与营销文案。
> 更新日期：2026-09-15 · 每次新增依赖/素材时必须同步更新本文件。

---

## 1. 总原则（红线）

1. **代码原创**：本项目源码（前端、Rust 引擎、预设库、脚本）均为独立编写。禁止整段复制其他项目代码；参考思想时用不同实现。
2. **开源可用但守许可证**：使用开源组件前确认其许可证，并在本文件登记。区分三类：
   - **宽松许可（MIT / Apache-2.0 / BSD / OFL）**：可自由商用，保留版权声明即可。
   - **强 Copyleft（GPL / AGPL）**：二进制分发需附许可证文本 + 源码可得性；**禁止把 GPL 代码复制进本项目源码**（否则整个项目受 GPL 约束）。
   - **专有 / 来源不明**：不使用。
3. **不抄视觉与文案**：UI 布局、图标、插画、营销文案必须原创或使用开源素材（如 lucide 图标，MIT）。禁止复制其他产品的宣传语、界面元素。
4. **功能参数不构成侵权**：编码参数（CRF/码率/keyint 等）属于功能性技术参数，不受版权保护；但**必须保留来源标注**，避免「抄产品」的观感与争议。
5. **商标的指示性使用**：落地页对比提及 Movavi 等品牌，仅作事实性对比（功能/价格），属商标指示性使用；不贬损、不冒充、不蹭官方背书。

## 4. 外部二进制（子进程调用，不链接）

> 策略：**子进程方式调用，程序本体不链接其代码** → 无 GPL 传染到本项目。但**随包分发二进制本身**仍需遵守其各自许可证。

| 二进制 | 许可证 | 分发义务 |
|---|---|---|
| ffmpeg（含 libx264/libx265 的 GPL 构建） | **GPLv3**（该构建） | 随包附 GPLv3 文本 + FFmpeg 源码可得性说明/链接；或改用 LGPL 构建 / 购买 FFmpeg 商业授权 |
| mozjpeg (cjpeg) | BSD-3-Clause | 保留声明 |
| pngquant | **GPLv3** 或商业授权 | 随包附 GPLv3 文本 + 源码链接（pngquant 官网提供） |
| libwebp (cwebp) | BSD-3-Clause | 保留声明 |
| libavif (avifenc) | BSD-2-Clause | 保留声明 |

> 落地做法（业界通行，格式工厂等同类软件同样处理）：安装包内附 `licenses/` 目录，含每个二进制的许可证全文与源码获取链接；官网发布页提供 FFmpeg/pngquant 源码下载链接。

## 6. 预设参数来源声明

- `presets.json` 中 B 站免二压参数（`crf 23.5 / preset slow / level 4.1 / keyint 590`）为社区公开编码参数，**功能参数不受版权保护**，但 UI 与代码中已保留 `note` 字段标注「参数来源：社区公开数据」，发布页同样标注。
- 平台硬约束（≤100KB / ≤25MB 等）来自平台官方规则与公开调研，属事实信息。

## 7. 流程要求（每次改动自查）

- [x] 新增 npm / cargo 依赖 → 登记到本文件第 2/3 节，确认许可证
- [x] 新增二进制 → 登记第 4 节，确认许可证与分发义务
- [x] 新增图片/字体/图标 → 确认来源与许可证（禁止未授权使用）
- [x] 引用他人代码/思路 → 用不同实现重写，并在代码注释说明参考来源
- [x] 发布打包 → 确认 `licenses/` 目录包含全部第三方许可证全文（已建，打包前重跑 `node scripts/gen-licenses.mjs`）
