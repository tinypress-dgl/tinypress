# TinyPress（速压）— MVP 产品方案

> 工作代号：TinyPress / 速压（正式名可调整）
> 版本：v0.1 · 日期：2026-09-15 · 状态：评审中
> 定位：**本地优先、场景预设驱动的图片+视频压缩桌面工具** —— 用户不学参数，只选平台，拖入即出合规文件。

---

## 1. 产品定位与差异化

一句话：给「内容创作者 / 电商运营 / 普通办公用户」一个不用懂码率参数的本地压缩工具：选平台 → 拖文件 → 拿到符合平台硬约束的文件。

差异化空位（来自 Top10 对标与桌面级深挖的交叉验证）：

| 维度 | 现状 | TinyPress 的打法 |
|---|---|---|
| 图片+视频二合一 | Movavi 图片仅转格式无感知压缩；小丸/格式工厂重视频轻图片 | **两者兼顾**，图片做感知压缩（mozjpeg/pngquant） |
| 国内场景预设矩阵 | 小丸只做 B 站一格；Movavi 预设是历史机型包袱 | **国内多平台预设矩阵**（B站/抖音/视频号/小红书/拼多多/淘宝/朋友圈/证件照…），预设 JSON 热更新 |
| 本地隐私 | 在线工具需上传；大厂有云端依赖 | **100% 本地处理**，数据不出机器，无上传无账号 |
| 现代 UX | 小丸 Tkinter 老旧；格式工厂广告多口碑翻车 | 现代 UI，拖入批量 + 对比预览 + 一键完成 |
| 商业模式 | Movavi 大版本再收费被吐槽；万兴订阅+AI积分双付费墙 | **买断制含大版本升级**（¥199 / $69） |

## 2. 目标用户与核心场景（P0）

| 用户群 | 场景 | 典型硬约束 | 付费动机 |
|---|---|---|---|
| B 站 UP 主 / 视频创作者 | 导出后压成 B 站「免二压」规格 | 1080P 码率 ≤3000kbps 档（免二压参数，VMAF 92.1） | 画质损失不可逆，愿意为「参数正确」付费 |
| 电商运营（拼多多/淘宝） | 商品主图压到平台要求 | 拼多多主图 ≤100KB | 平台强制，无替代方案，刚需 |
| 微信生态用户 | 朋友圈/视频号视频 | 朋友圈视频 ≤25MB | 分享刚需 |
| 普通办公/证件场景 | 证件照等小体积图片 | 证件照 ≤200KB | 低频但强需求 |

> 注：B站 3000kbps / 拼多多 100KB / 朋友圈 25MB / 证件照 200KB 为对标调研确认的 P0 预设数字；抖音、视频号、小红书、淘宝等其余平台的完整硬约束见《对标深挖报告》附录《12 个国内平台预设硬约束表》，落地前逐项核实并写入预设 JSON。

## 3. MVP 功能范围

### P0 —— MVP 必须（8 周内）
1. **拖入批量文件**（图片+视频混合，多选/拖拽/粘贴）
2. **视频压缩**：x264/x265 预设参数，内置小丸 B 站免二压参数（`--crf 23.5 --preset 8 --level 41 -I 590`）
3. **图片感知压缩**：mozjpeg (cjpeg) / pngquant / libwebp (cwebp) / libavif (avifenc)，质量优先的感知压缩
4. **4 个国内场景预设**：B站、抖音、视频号、拼多多主图（另附微信朋友圈、证件照两个备用）
5. **结果对比**：压缩前后大小、预计 vs 实际、可放大预览对比（AVIF/WebP 支持）
6. **批量队列**：并发 2-4 个任务、进度条、完成通知、失败重试
7. **100% 本地**：无上传、无账号、可离线
8. **Windows 优先**，macOS 同步可跑

### P1 —— 1.0 发布后 1-2 个月
- 平台预设扩充到 12+（小红书、淘宝、YouTube、TikTok、视频号横竖屏分设）
- 文件夹监控（放进文件夹自动压缩）
- 预设自定义编辑器（改参数另存，JSON 导出/导入）
- 硬件加速可选（NVENC / QSV / VideoToolbox），默认软件编码保证画质
- 基础视频编辑（截取、裁剪、旋转、去黑边）

### P2 —— 远期
- 社区预设分享、预设库云同步（可选）
- AV1 硬件编码（新显卡）
- 命令行接口 / 批量脚本
- macOS 全量适配 + 上架 Mac App Store

## 4. 技术选型与架构

### 4.1 技术栈（依据对标调研结论）
| 层 | 选型 | 理由 |
|---|---|---|
| 桌面框架 | **Tauri 2.0**（Rust + Web 前端） | 首包 <80MB 目标、内存占用低、跨平台（Win/macOS） |
| 前端 | React 18 + TypeScript + Vite + Tailwind CSS | 生态成熟、开发快、UI 现代化 |
| 视频引擎 | **FFmpeg 静态二进制**（子进程调用，含 libx264/libx265/SVT-AV1） | 商业转换器都是 FFmpeg 封装，3 个月可出 MVP |
| 图片引擎 | mozjpeg (cjpeg) / pngquant / libwebp (cwebp) / libavif (avifenc) 子进程 | 感知压缩质量远超通用库；Movavi 未做，是差异化 |
| 并发 | Rust tokio 任务池 + 子进程 | 队列/进度可控，崩溃隔离 |
| 预设库 | **JSON 文件热更新**（随包分发 + 可选远程拉取） | B 站码率规则已改 4 次，不硬编码 |

### 4.2 架构（逻辑分层）
```
┌──────────────────────────────────────────────┐
│ 前端 UI（React/TS）                           │
│  拖入区 · 预设选择 · 队列列表 · 对比预览       │
└────────────────────┬─────────────────────────┘
                     │ Tauri IPC (invoke/event)
┌────────────────────▼─────────────────────────┐
│ Rust 后端（src-tauri）                        │
│  commands.rs（命令入口）                      │
│  engine/queue.rs（tokio 任务队列）            │
│  engine/video.rs（FFmpeg 参数组装+spawn）     │
│  engine/image.rs（图片引擎调度）              │
│  presets/（预设加载与校验）                   │
└────────────────────┬─────────────────────────┘
                     │ spawn（不链接，规避 GPL 传染）
┌────────────────────▼─────────────────────────┐
│ 外部二进制：ffmpeg / cjpeg / pngquant /       │
│  cwebp / avifenc（随包分发，遵守各自许可证）  │
└──────────────────────────────────────────────┘
```

### 4.3 关键工程决策
- **子进程而非库链接**：FFmpeg（GPL 构建）作为独立进程调用，程序本体不静态链接其代码，规避 GPL 传染；随包分发时随附 FFmpeg 许可证与源码可得性说明（业界通行做法，格式工厂等同理）。
- **预设 JSON 热更新**：`presets.json` 结构稳定、字段齐全；平台规则变化只改 JSON 不发版（远程更新做成 P1，先内置 + 版本字段）。
- **体积控制**：FFmpeg 仅裁剪所需组件（libx264/libx265/SVT-AV1/常见解封装解码器），目标首包 <80MB。

## 5. 预设 JSON 结构设计（v1）

```jsonc
{
  "schema_version": 1,
  "updated_at": "2026-09-15",
  "presets": [
    {
      "id": "bilibili-1080p",
      "name": "B站 1080P（免二压）",
      "platform": "bilibili",
      "kind": "video",
      "tags": ["creator", "hot"],
      "constraints": { "max_bitrate_kbps": 3000, "max_resolution": "1920x1080" },
      "video": {
        "codec": "libx264",
        "crf": 23.5,
        "preset": "slow",
        "level": "4.1",
        "keyint": 590,
        "pix_fmt": "yuv420p",
        "audio": { "codec": "aac", "bitrate_kbps": 192 }
      },
      "filters": { "scale": "1920:-2", "fps": 60 },
      "note": "小丸免二压参数：--crf 23.5 --preset 8 --level 41 -I 590（VMAF 92.1）"
    },
    {
      "id": "pdd-main-image",
      "name": "拼多多主图（≤100KB）",
      "platform": "pinduoduo",
      "kind": "image",
      "constraints": { "max_size_kb": 100, "min_resolution": "480x480" },
      "image": {
        "format": "jpeg",
        "engine": "mozjpeg",
        "quality_target": "max_size",
        "max_size_kb": 100,
        "strip_metadata": true
      }
    }
    // 其余预设：douyin-vertical、shipinhao、wechat-moments(≤25MB)、cert-photo(≤200KB)…
  ]
}
```

- 视频预设：`codec/crf/preset/level/keyint/audio/filters` 直接映射 FFmpeg 参数。
- 图片预设：`engine/max_size_kb/quality_target` 驱动「两段式压缩」（先质量试探，再二分逼近目标大小）。
- 所有预设带 `note` 字段，UI 可展示参数依据，建立专业信任。

## 6. 8 周开发排期（MVP）

| 周 | 里程碑 | 交付物 |
|---|---|---|
| W1 | 项目骨架 + FFmpeg 集成打通 | Tauri 工程、拖入区 UI、ffmpeg spawn 冒烟测试 |
| W2 | 视频压缩管道 | x264/x265 参数组装、预设 JSON 加载、B站预设跑通 |
| W3 | 图片压缩管道 | cjpeg/pngquant/cwebp/avifenc 集成、两段式目标大小压缩 |
| W4 | 队列 + 对比预览 | 并发队列、进度事件、前后对比预览 UI |
| W5 | 预设库 + 全流程测试 | 4-6 个 P0 预设入库、真实素材回归测试 |
| W6 | 打包与签名 | Windows 安装包（NSIS）、SmartScreen 签名、官网落地页 |
| W7 | 验证视频 + 内测 | 演示视频上线（B站/小红书）、V2EX/少数派内测发放 |
| W8 | 发布 + 迭代 | 公测发布、首周数据复盘、P1 优先级调整 |

> 8 周为紧凑排期；若业余时间开发，按 12 周执行（W3/W6 各 +2 周缓冲）。

## 7. 商业化与定价

| 项 | 方案 | 依据 |
|---|---|---|
| 海外定价 | **$69 买断**（含大版本升级） | 对标 Movavi $64.95；「含大版本升级」正面打其软肋 |
| 国内定价 | **¥199 买断**（首发价 ¥99-129 促销），比 Movavi 中国区 ¥279 低 56% | 调研结论：国内 ¥68-128 买断甜点区，卡位价 |
| 免费版 | 单文件压缩 + 2 个预设 + 水印开关；**按功能分级而非限时** | 防白嫖同时保留转化钩子 |
| 支付 | 海外：Paddle / Lemon Squeezy（自动开票、EU VAT）；国内：官网支付宝/微信 + 数码荔枝等分销 | 双市场收款 |
| 升级策略 | 大版本免费升级承诺写进购买页 | 用户最痛点的反向营销 |

## 8. 风险与避坑清单

| 风险 | 应对 |
|---|---|
| B 站等平台规则频繁变更 | 预设 JSON 化 + 版本字段，规则变了只发 JSON |
| FFmpeg GPL 许可证合规 | 子进程调用不链接；随包附许可证说明与源码可得路径 |
| 预设参数抄袭被指摘 | 参数本身无版权，但 UI/文案原创；可标注「参数来源：社区公开数据」 |
| 免费替代品（PowerToys/在线站）分流 | 主打「批量 + 多平台预设 + 本地隐私」组合拳，单点功能不硬拼 |
| 代码签名缺失导致 SmartScreen 拦截 | W6 预留签名预算（EV 或 OV 证书） |
| 装机量上不去 | 先做验证视频测需求（见 GO-TO-MARKET.md），确认后再投入 W6-W8 |

## 9. 成功指标（MVP 阶段）

- 内测报名 ≥30 人（表单留资）
- 验证视频 B 站播放 ≥5k、互动 ≥100
- 公测 4 周：下载 ≥2k，付费转化 ≥2%，收入 ≥¥8000（约 40-60 份）
- 复购/口碑：NPS 或口碑提问（「你会推荐给同事吗」）≥40%
